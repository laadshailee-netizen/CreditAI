# 🏦 CreditAI - AI Powered Credit Scoring System

## What is this?
CreditAI is a smart, responsive web app that checks if a person should get a loan or not. It uses AI logic to give a Credit Score from 300 to 850.

## Features
- Secure Staff Login
- Dashboard with Total / Approved / Rejected stats
- New Credit Check with AI Analysis
- EMI Calculation and EMI / Income Ratio
- AI Recommendation - Approve / Review / Reject
- Why This Score? - Explainable AI
- Download Report
- Application History
- 100% Responsive - Works on Mobile, Tablet & Desktop

## How to Run
pip install -r requirements.txt
py -m streamlit run streamlit_app.py
